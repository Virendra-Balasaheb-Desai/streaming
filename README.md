# 🎬 Video Streaming Platform

A full-stack video streaming platform similar to YouTube, built with a separate React frontend and Node.js/Express backend.

This project is maintained as two independent repositories:

## 🖥️ Frontend

A React-based frontend for browsing videos, viewing video details, posting comments, and interacting with the platform.

Repository:

https://github.com/Virendra-Balasaheb-Desai/streaming-frontend

Tech Stack:

React
JavaScript
Tailwind CSS
React Router

## ⚙️ Backend

A RESTful backend API responsible for authentication, video management, comments, tweets, file uploads, and database operations.

Repository:

https://github.com/Virendra-Balasaheb-Desai/streaming-backend

Tech Stack:

Node.js
Express
MongoDB
Mongoose
JWT
Multer
Cloudinary
bcrypt

The frontend and backend are maintained as separate Git repositories, allowing each application to have its own Git history, development workflow, and deployment process.
